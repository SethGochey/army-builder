Paste Format Reference

The spreadsheet paste feature accepts tab-separated rows in this format:

DATASHEET[tab]Name[tab]Models[tab]Wounds[tab]T[tab]Save[tab]Invuln[tab]FNP
SHOOT[tab]Name[tab]Range[tab]Attacks[tab]BS[tab]S[tab]AP[tab]Damage
MELEE[tab]Name[tab]Attacks[tab]WS[tab]S[tab]AP[tab]Damage

Save values accept: 3, 3+, or - (no save). Attacks/Damage accept D6, 2D6+1, etc.
